# iOS app screenshots

Placeholder folder for the iPhone and iPad app's screenshots; no images are committed yet. The main README links
these file names, so a capture saved under the same name shows up there without further edits.

| File | Device | Screen |
|---|---|---|
| `iphone-dashboard.png` | iPhone | Sessions list with attention triage and the connection banner |
| `iphone-session.png` | iPhone | A session's live transcript with the composer and a queued message |
| `iphone-diff.png` | iPhone | Diff review: word highlights, a line comment, the Viewed mark |
| `ipad-split-diff.png` | iPad | Split (side-by-side) diff next to the session list |
| `iphone-pairing.png` | iPhone | Add host: QR pairing and the plain-HTTP warning |

Capture on a simulator or device in light and dark appearance as needed (Xcode: *Device ▸ Trigger Screenshot*, or
`xcrun simctl io booted screenshot <file>.png`), with no real hosts, tokens or private session content visible.
